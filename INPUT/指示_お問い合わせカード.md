# 指示：トップページ「アクセス」の地図の右の「お問い合わせ」カードを作り直す

トップページ（site/index.html）の「アクセス」で、地図の右にある「お問い合わせ」カード（div.contact-panel）を、見本画像に近い見た目に作り直してください。

## 見本と画像
- 見本（見るだけ。サイトには使わない・コピーしない）：
  /Users/kazuhide/academia/src/sato-clinic_html/site/assets/images/mapsidePoster.png
- 見本から切り出した画像は、もう置いてあります（作らなくてよい）：
  - site/assets/images/contact-illust.jpg（建物のイラスト、1301×287）
  - site/assets/images/contact-leaves.jpg（右上の葉、461×215）

## 守ること
- 対象はデスクトップ・タブレット・スマホのすべての版。ただし変えるのは、アクセスの「地図とカードの並び」と「カードの中」だけ。ほかの部分は変えない。
- 文言は掲載原稿のまま。見本にある「診療やご予約、各種ご相談など、お気軽にお問い合わせください。」「お電話でのお問い合わせ」「メールでのお問い合わせ」は、原稿にないので入れない。
- 電話番号は tel:0000000000 のリンクにする。
- メールアドレスは掲載原稿どおり、すべて小文字の info@sato-clinic-test.jp にする（今の index.html は「sato-Clinic」と大文字の C になっていて誤り）。
- 色は見本の青緑ではなく、今のサイトの緑のままにする。
- CSS は style.css のいちばん最後に追加し、既存のルールは書き換えない。

## 3. 確認（1440 / 1024 / 375 / 280px の4つだけ）
画像は loading="lazy" なので、確かめる前に loading を eager に変えて読み込ませること。
- 各幅で .map-embed と .contact-panel の幅と高さ
- 各幅で、カードの中の文字や枠がカードの外にはみ出していないか
- 375px：住所が「〒123-4567」「東京都台東区上野0-0-0」の2行になり、番地の途中で折り返していないか
- メールのリンク先が mailto:info@sato-clinic-test.jp になっているか（大文字の C が残っていないか、index.html 全体で検索）
- 横スクロール（document.documentElement.scrollWidth）。280px ではフッターの住所が原因で、前から約 10px はみ出しているので、それ以上増えていなければよい

を報告してください。
