# 佐藤医院サイト（トップ修正版＋下層ページ）

## 置き方
今の制作フォルダに上書きしてください（念のため元の index.html と css/style.css は控えを取ってから）。
`js/main.js` と `assets/images/` は今のものをそのまま使います。index.html をダブルクリックすれば全ページを行き来できます。

## トップページで直したこと
- 「準備中」だったリンク18か所に行き先を付けた（お知らせ・院長あいさつ・診療内容・当院について・スタッフ・FAQ・予約）
- スマホで診療内容がお知らせより上に来ていた並べ替え（order）を外し、依頼書どおり 診療時間→お知らせ の順に
- アクセス欄：Googleマップを埋め込み（住所が架空なのでJR上野駅付近を表示）
- アクセス欄：PCでは画像の文字だったお問い合わせ・住所・駐車場を、HTMLの文字で表示（画像 temp-image-21 は使わなくなった）
- PCのヘッダーにも「ご予約・ご相談」ボタンを表示（1180px幅でも収まるよう余白を調整）
- フッターのナビに「ご予約・ご相談」を追加
- 白文字の背景・小さい緑文字を濃い緑 #287d72 に（白とのコントラスト 4.1 → 4.9）。休診の「／」も少し濃く
- 効いていなかったCSS（電話ボタンのグラデーションなど）を削除
- 院長の仮枠画像の alt を空に（仮枠なのに「院長 佐藤 太郎」と読み上げられていたため）
- フォント・文字サイズは変更していません

## まだ残っていること（写真の書き出しが必要）

## 下層ページ
| ファイル | ページ |
|---|---|
| message.html | 院長あいさつ |
| reservation.html | ご予約・ご相談 |
| reservation-complete.html | 送信完了 |
| news.html | お知らせ |
| medical.html | 診療内容 |
| about.html | 当院について（スタッフ紹介を含む） |
| faq.html | よくあるご質問 |
| access.html | 診療時間・所在地（PNGなし。依頼書と原稿から作成） |

写真は灰色の仮枠です。決まったら `<img class="photo" style="--ratio: 3 / 2;" src="…" alt="…">` に差し替えてください。

## 注意
- 予約フォームは表示確認用に完了ページへ飛ぶだけです。本当に送るには受け取り先（フォーム送信サービス等）を決め、`action` を変えて `method="post"` に。
- 予約・送信完了ページの案内文は原稿にない文なので、医院への確認が必要です。
- Googleマップはネットにつながった状態でないと表示されません。
