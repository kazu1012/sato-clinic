# 佐藤医院 Webサイト 「ご予約・ご相談」ページに追加する文言のご確認

2026年11月12日

Webフォームから送られた内容が当院に届くようにするため、「ご予約・ご相談」ページと「送信完了」ページに、**原稿・依頼書にない文言**を追加します。
どの場面で、どこに、どの文字が出るかを下にまとめました。

- 文言を変えたい場合は、各表の「変更後の文言」欄にご記入ください。空欄の項目は、そのまま使用します。
- 原稿にある文言（入力欄の名前、個人情報の説明、「送信後、当院より確認のご連絡をいたします。…」など）は変えていません。
- 画面の文言のほかに、患者様に自動でお送りするメールの文面もあります（「4. 受付確認メール」）。

---

## 1. 入力に誤りがあるとき（「ご予約・ご相談」ページ）

「送信する」を押したときや、欄に入力し終えたときに、入力に誤りがあると表示されます。

### (1) フォームの上：エラーの一覧

「Webでのご予約・ご相談」の見出しのすぐ下に、赤い枠で表示します。

| 表示する文字 | 変更後の文言 |
|---|---|
| 入力内容をご確認ください（○件） | |

その下に、誤りのある欄を「欄の名前：(2) の文言」の形で並べます。
例：「お名前：お名前を入力してください。」　押すと、その欄に移動します。

### (3) 追加する入力欄：メールアドレス（確認用）

メールアドレスの打ち間違いで受付確認メールが届かないことを防ぐため、「メールアドレス」の欄のすぐ下に、もう一度入力していただく欄を追加します。「必須」の印は付けません（メールアドレス自体が任意のため）。
この欄の内容は画面での確認だけに使い、当院には送られません。

| 場所 | 表示する文字 | 変更後の文言 |
|---|---|---|
| 欄の名前 | メールアドレス（確認用） | |

確認用の欄の誤り（空のとき・一致しないとき）は、(2) の表の「メールアドレス（確認用）」の行の文字を表示します。

「午前 / 午後」の選択肢のうち「午後」を選べなくし、選択肢の文字を次のように変えます。

| 場所 | 表示する文字 | 変更後の文言 |
|---|---|---|
| ご希望日の「午前 / 午後」の選択肢 | 午後（土曜は休診） | |

## 3. 送信するとき

### (1) 送信中（「ご予約・ご相談」ページ）

| 場所 | 表示する文字 | 変更後の文言 |
|---|---|---|
| 「送信する」ボタン（送信が終わるまでの数秒間） | 送信中… | |

### (2) 送信できなかったとき（「ご予約・ご相談」ページ）

フォームの上に、赤い枠で表示します。入力した内容は消えないので、もう一度送信できます。

| 表示する場面 | 1行目に表示する文字 | 変更後の文言 |
|---|---|---|
| 通信の不具合など | 送信できませんでした。 | |
| 送信が集中しているとき（1時間に30件を超えたとき） | 現在、送信が混み合っています。時間をおいてお試しいただくか、お電話でご連絡ください。 | |
| 受付のしくみ（Google）で不具合が起きたとき | 送信処理でエラーが発生しました。お手数ですが、お電話でご連絡ください。 | |

1行目の下に、どの場面でも次の2行を表示します。

| 表示する文字 | 変更後の文言 |
|---|---|
| 時間をおいて、もう一度お試しください。 | |
| お急ぎの場合は、お電話（00-0000-0000）でご連絡ください。 | |

### (3) 送信できたとき（「送信完了」ページ）

「佐藤医院へお問い合わせいただき、ありがとうございます。」のすぐ下に表示します。

| 表示する文字 | 変更後の文言 |
|---|---|
| 受付番号：SATO-261112-0001（番号は申し込みごとに変わります） | |

※ 次の文字は、Google に接続する前の確認のときだけ表示されます。本番では表示されません。
「※テスト表示です。まだGoogleに接続していないため、実際には送信されていません。」

## 4. 受付確認メール（患者様にお送りするメール）

患者様がメールアドレスを入力した場合に、送信後すぐ自動でお送りします。

```
件名：【佐藤医院】ご予約・ご相談を受け付けました（受付番号）

○○ 様

このたびは佐藤医院にご予約・ご相談をいただき、ありがとうございます。
以下の内容で受け付けました。

受付番号　　：SATO-261112-0001
お名前　　　：○○（○○）様
電話番号　　：○○
メール　　　：○○
ご希望の内容：○○
初診・再診　：○○
第1希望　　 ：2026年11月16日（月）　午前
第2希望　　 ：（なし）

【ご相談内容】
○○

送信後、当院より確認のご連絡をいたします。ご連絡をもってご予約の確定となります。
お急ぎの場合は、お電話でご連絡ください。

────────────
佐藤医院
〒123-4567　東京都台東区上野0-0-0
TEL：00-0000-0000
受付時間：午前 8:00〜11:00 ／ 午後 12:00〜17:00
休診日：木曜・土曜午後・日曜
────────────
※このメールは送信専用の自動送信です。お心当たりのない場合は、お手数ですが破棄してください。
```

- 変更したい箇所があれば、上の文面に直接書き込むか、別途お知らせください。
- 課題の期間中は、メールの最後に「※このメールは、教材用の架空の医院「佐藤医院」のフォームから送信されたテストです。」が付きます。本番では外します。
- 当院あての通知メール（院内で受け取るもの）は、患者様には見えないため、ここには載せていません。

## 5. 追加しない文言

次の2つは、なくても入力・送信に困らないため、原稿にない文言を増やさないよう**表示しません**。表示をご希望の場合はお知らせください。

| 場所 | 文言 |
|---|---|
| ご相談内容の欄の下 | 0 / 1000文字（入力した文字数） |
| メールアドレスの欄の下 | ご入力いただくと、受付確認のメールをお送りします。 |

## 6. 制作メモ（文言を直す場所）

| 文言 | ファイル |
|---|---|
| 1.・2.・3.(1)(2) の画面の文言 | `js/reservation.js`（`RULES`・`showSummary`・`showFailure`・`syncTimeOptions` など） |
| 1.(3) 確認用の欄の名前 | `reservation.html`（確認用の誤りの文言は `js/reservation.js` の `RULES.email2`。Google 側にはない） |
| 1.(2) の文言のうち、Google 側でも確認するもの・3.(2) の「混み合っています」「送信処理でエラー」 | `sato-contact/gas/Code.gs`（`validate_`・`checkDate_`・`doPost`）。画面と Google 側は同じ文言にそろえる |
| 3.(3) 受付番号・テスト表示 | `reservation-complete.html` |
| 4. 受付確認メール | `sato-contact/gas/Code.gs`（`sendAutoReply_`・`summaryText_`） |

- 画面に見えない文字として、迷惑送信よけの隠し欄の名前「website」があります（人には表示されず、読み上げもされません）。
- 文言を変えた場合は、`sato-contact` フォルダで `npm test` を実行して確認します（テストが一部の文言を確かめているため）。
