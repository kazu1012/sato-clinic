## 2. ご確認いただきたいこと

**① お知らせの更新方法**
院長先生やスタッフの方が、ご自身でお知らせを投稿・更新されますか？
- **ご自身で更新される場合**：管理画面から投稿できるしくみ（お知らせ専用の更新サービスなど）の導入をご提案します。費用と方法は別途お見積りします。
- **制作側に依頼される場合**：今回の方法（1つのファイルを書き換える）で対応できます。

**② お知らせの投稿日**
お知らせに投稿日を表示するかどうか、表示する場合は各お知らせの日付を教えてください。
（「年末年始の休診について」の曜日は、上記 (7) のとおり今年の暦に合わせて修正済みです。）

**③ 地図の表示場所**
住所が仮のもの（上野0-0-0）のため、地図は今「JR上野駅」を表示しています。正式な住所が決まりましたら、医院の場所を表示するように直します。

**④ 原稿にない文章の掲載可否**
次の文章は原稿にないため、掲載してよいかご確認ください。
- 「ご予約・ご相談」ページ：入力欄の名前（お名前・ふりがな・ご希望日など）、個人情報の取り扱いの説明、「送信後、当院より確認のご連絡をいたします。ご連絡をもってご予約の確定となります。」
- 「送信完了」ページの本文すべて
- 「診療時間・所在地」ページの英語の案内（上記 (6)）

**⑤ 公共交通機関のご案内**
依頼書では「公共交通機関の利用方法を記載」が必須ですが、原稿には「JR上野駅より徒歩5分」のみです。より分かりやすくするため、次の情報をいただけますか。
- 最寄りの出口（例：JR上野駅 ○○口）と駅からの道順
- 地下鉄・バスを利用する場合の最寄り駅・停留所

**⑥ 表記について**
- 原稿の「院長挨拶」を、サイトでは読みやすさを考えて「院長あいさつ」と表記しています。このままでよろしいですか。
- メニューの「アクセス」は「診療時間・所在地」ページにつながっています。メニューの幅に限りがあるため短い表記にしていますが、「診療時間・アクセス」などへの変更をご希望でしたらお知らせください。

**⑦ 写真について**
- 支給写真のうち、トップページの大きな写真と院長写真には文字が入っています。文字のない元の写真をいただければ、よりきれいに表示できます。
- 「健康診断」「予防接種」「禁煙外来」「医院の理念・方針」に合う写真があれば、追加でいただけますか。
