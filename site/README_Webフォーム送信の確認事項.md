# 佐藤医院 Webサイト Web予約フォームの送信について（ご提案と確認のお願い）

2026年11月12日

「ご予約・ご相談」ページのWebフォームは、今は見た目だけの状態で、送信しても内容が当院に届きません。
このフォームから送られた内容が当院に届き、メールで返信できるようにする作業をご提案します。

## 2. 作業後の状態（ご提案）

### (1) 送られた内容が当院に届きます

```
患者様がフォームから送信
        │
        ▼
Google のしくみで受け付け（無料のGoogleアカウントで動きます）
        ├─ 受付一覧（Googleスプレッドシート）に1件ずつ記録
        │     受付番号・対応状況（未対応／対応済み）を付けて管理できます
        ├─ 当院に通知メールが届く
        │     「返信」を押すだけで、患者様にメールが届きます
        └─ 患者様がメールアドレスを入力していれば、受付確認メールを自動でお送りします
```

### (2) 送信完了ページに受付番号を表示します

送信が完了すると、今の「送信完了」ページに移り、受付番号（例：SATO-261112-0001）を表示します。
お電話で問い合わせがあったときに、受付番号でどの申し込みかを確認できます。

### (3) 送信前に入力内容を確認します

| 項目 | 確認する内容 |
|---|---|
| お名前・ふりがな・電話番号・ご希望の内容・初診/再診・第1希望・個人情報の同意 | 入力されているか |
| ふりがな | ひらがなか（カタカナで入力された場合は、自動でひらがなに直します） |
| 電話番号 | 0から始まる10〜11桁か（全角で入力された場合は、自動で半角に直します） |
| メールアドレス | 入力は任意。入力された場合は形式が正しいか |
| ご希望日 | 明日から3か月先までか。木曜・日曜は選べません。土曜は午前のみです |
| ご希望日（第2希望） | 入力は任意。第1希望と同じ日時は選べません |
| ご相談内容 | 1000文字以内か |

- 入力に誤りがあるときは、その欄の下とフォームの上に、直すところをお知らせします。
- 送信できなかったとき（通信の不具合など）は、お電話番号を添えて、もう一度お試しいただくようご案内します。

### (4) いたずら・事故を防ぎます

- 機械による迷惑な送信を見分けて、受け付けないようにします。
- 1時間に受け付ける件数に上限（30件）を設けます。
- 同じメールアドレスへの受付確認メールは、10分に1回までにします（他人のアドレスを入れて何度も送信されても、大量にメールが届かないようにするため）。

### (5) 変えないこと

- ページの見た目と、掲載原稿の文言は変えません。
- 新しいページは増やしません（今の「ご予約・ご相談」「送信完了」ページを使います）。

## 3. ご確認いただきたいこと

**① 原稿にない文言の表示**
しくみ上、次の文言を画面に表示する必要があります。原稿にない文言のため、掲載してよいかご確認ください。

| | 文言（例） | 表示する場面 | ご提案 |
|---|---|---|---|
| (a) | 「お名前を入力してください。」「木曜日は休診日です。別の日を選択してください。」など／「入力内容をご確認ください（3件）」／「送信できませんでした。時間をおいて、もう一度お試しください。」／「送信中…」 | 入力の誤りや送信の失敗があったとき | 表示する（ないと、患者様がどこを直せばよいか分かりません） |
| (b) | 「受付番号：SATO-261112-0001」 | 送信完了ページ | 表示する |
| (c) | 「※テスト表示です。…実際には送信されていません。」 | 準備中の確認のときだけ（本番では表示されません） | 表示する |
| (d) | 「午後（土曜は休診）」 | 希望日に土曜日を選んだときの時間帯の選択肢 | 表示する |
| (e) | 「0 / 1000文字」 | ご相談内容の欄の下（入力した文字数） | 表示しない |
| (f) | 「ご入力いただくと、受付確認のメールをお送りします。」 | メールアドレスの欄の下 | 表示しない |

**② 受付確認メール・通知メールの文面**
患者様にお送りする受付確認メールの文面も原稿にはありません。案は次のとおりです。ご確認ください。

```
件名：【佐藤医院】ご予約・ご相談を受け付けました（受付番号）

○○ 様

このたびは佐藤医院にご予約・ご相談をいただき、ありがとうございます。
以下の内容で受け付けました。

（受付番号・お名前・電話番号・ご希望の内容・ご希望日・ご相談内容）

送信後、当院より確認のご連絡をいたします。ご連絡をもってご予約の確定となります。
お急ぎの場合は、お電話でご連絡ください。

────────────
佐藤医院
〒123-4567　東京都台東区上野0-0-0
TEL：00-0000-0000
受付時間：午前 8:00〜11:00 ／ 午後 12:00〜17:00
休診日：木曜・土曜午後・日曜
────────────
```

**③ 「初診・再診」の最初の状態**
- **今のまま（どちらも未選択・必ず選んでいただく）**：選び忘れを防げます。〔ご提案〕
- **「初診」を最初から選んだ状態にする**：入力の手間は減りますが、再診の方が直し忘れるおそれがあります。

**④ 使用するGoogleアカウント**
今は、確認用として **制作者の個人のGoogleアカウント** で動かす予定です。そのため、
- 受付確認メールの差出人として、制作者の個人のメールアドレスが患者様に見えます。
- 通知メールと受付一覧も、制作者のアカウントに届きます。

本番で使う場合は、**医院用のGoogleアカウント**（例：○○@gmail.com）をご用意いただき、そちらに切り替えることをご提案します。
- 医院用のアカウントをご用意いただけますか。
- 通知メールは、どのアドレスで受け取りますか（院長先生／受付スタッフなど）。
- 無料のGoogleアカウントで送れるメールは **1日100通まで** です。通常の件数であれば足ります。

**⑤ 個人情報の取り扱い**
フォームでは、お名前・電話番号のほか、症状などのご相談内容をお預かりします。
- 受付一覧はGoogleのサービス（スプレッドシート）に保存されます。この保存方法でよろしいですか。
- 本番で使う前に、**プライバシーポリシー（個人情報の取り扱い）のページ**を用意することをおすすめします。文面をご用意いただくか、作成のご依頼をお願いします。

## 4. 決まった内容と理由

| | 決まった内容 | 理由 |
|---|---|---|
| ① 原稿にない文言 | (a)〜(d) は表示する。(e) 文字数カウンターと (f) メールアドレス欄の注記は表示しない | (a)(b) がないと、患者様がどこを直せばよいか、どの申し込みかが分からず、しくみとして成り立たないため。(c) は準備中の確認のときにしか出ず、(d) は休診の時間帯を選べないことを伝えるのに必要なため。(e)(f) はなくても入力・送信に困らないため、原稿にない文言をできるだけ増やさない方針で表示しないことにしました |
| ② 受付確認メール | 送る。文面は「3. ②」の案のとおり | 送信できたことを患者様がメールでも確かめられ、受付番号も手元に残るため。文面の案内文は、ページの原稿「送信後、当院より確認のご連絡をいたします。…」と同じ内容にしています |
| ③ 初診・再診 | 最初から選んでおかない（必須のまま、ご本人に選んでいただく） | 「初診」を最初から選んでおくと、再診の方が直し忘れたまま送信してしまうおそれがあるため |
| ④ Googleアカウント | 課題の期間は制作者のGoogleアカウントで動かし、通知メールも同じアカウントで受け取る。本番では医院用のアカウントに付け替える | 課題の確認には制作者のアカウントで足り、医院用のアカウントがまだないため。本番で付け替えないと、患者様に制作者の個人アドレスが見え、受付内容も制作者に届いてしまうため（付け替えの手順は「5. 制作メモ」） |
| ⑤ 個人情報 | ご相談内容は受付一覧（Googleスプレッドシート）に保存する。プライバシーポリシーのページは今回は作らない | 受付一覧で対応状況を管理するには、ご相談内容も一緒に残す必要があるため。ただし症状などの個人情報をお預かりするので、**本番公開の前にプライバシーポリシーのページが必要**です（「5. 制作メモ」） |

- JavaScript が動かない環境では、送信できません（入力内容が URL に載らないよう `method="post"` にしています）。

### 本番公開の前に必要なこと

1. **医院用のGoogleアカウントに付け替える**（「4. ④」）
   - 医院用のアカウントで `sato-contact/README.md` の「Google 側の設定」を最初からやり直す
   - `sato-contact/gas/Code.gs` の `CONFIG.NOTIFY_TO`（通知メールの宛先）を医院のアドレスに変える
   - 新しく公開した URL を `js/reservation.js` の `GAS_URL` に貼り直す
   - `CONFIG.TEST_NOTE`（「教材用の架空の医院…テストです」という注記）を空にする
2. **プライバシーポリシーのページを用意する**（「4. ⑤」）。文面は医院からいただくか、作成のご依頼をいただく
3. 正式な住所・電話番号が決まったら、受付確認メールの文面（Code.gs）とページの電話番号のリンクも合わせて直す
