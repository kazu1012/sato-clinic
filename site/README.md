# 佐藤医院 トップページ

ローカルの静的HTML/CSS実装です。外部サービスへの公開は行っていません。

## 表示

`index.html` をブラウザーで開いてください。ビルド・パッケージインストール・外部フォントは不要です。

- HTML: `index.html`
- CSS: `css/style.css`
- JavaScript: `js/main.js`（共通ナビゲーションの開閉のみ）
- 正式ロゴ: `assets/images/logo.png`（`INPUT/assets/logo.png` を加工せずコピー）
- 仮画像: `assets/images/`（支給されたPNG全21点を、ファイル名・内容を変更せずコピー）

## 基準とレスポンシブ

制作依頼書 → 掲載原稿 → design.json → reference.png の順で内容を判断しています。ロゴは追加指示に従い、`INPUT/assets/` の正式素材を優先しています。写真は指定されたtemp-imagesのみです。外部画像・生成画像・外部フォントは使用していません。

1440pxでは主要幅1200px、ヘッダー60px、ヒーロー480pxを基準とし、色・余白・カード・文字組みを支給デザインへ合わせています。本文の固定高やページ全体の絶対配置は使用していません。

ブレークポイントは1180px、860px、600pxです。共通HTMLをメディアクエリで再配置します。

| 幅 | 診療カード | スタッフカード | ナビゲーション |
| --- | --- | --- | --- |
| 1440px | 4列 | 3列 | 横並び |
| 768px | 2列 | 2列 | 開閉式 |
| 390px | 1列 | 1列 | 開閉式・2列の項目配置 |

スマートフォンでもPCと同じく、診療時間 → お知らせ → 院長あいさつ → 診療内容 → 当院について → スタッフ → FAQ → アクセスの順です（制作依頼書 4-2 の順序）。2026年11月の修正内容は「README_修正内容と確認事項.md」を参照してください。

本文はPC・Tabletで原則17px、Smartphoneで16px、操作対象は狭い画面で44px以上（主要ボタンは48px以上）です。表の時刻・補足等は別サイズです。画像の比率を維持し、写真の限定的な切り抜きにはobject-fitを使用しています。

## 実装時の判断・支給デザインとの差

1. 1448pxへのはみ出しは再現せず、主要領域を中央寄せにしました。フッター下の約570pxの空白も除きました。
2. 不整合のあるAuto Layout値、重複枠、空フレームは転記せず、通常のGrid/Flexboxと本文に追従する高さへ置き換えました。
3. 見出し・ナビゲーションの「院長あいさつ」「医院長あいさつ」は、上位資料の「院長挨拶」を使用しました。全文ボタンの「院長あいさつの全文へ」はJSONのUI文言を保持しています。
4. 「診察内容をもっとみる」は「診療内容」と用語が異なります。独自の修正文を作らず、上位資料の「診療内容」をボタンラベルとして採用しました。
5. 「09:00」は基本情報マスタの「9:00」を使用しました。診療時間・受付時間・休診日等はマスタと一致させています。
6. トップFAQはPCデザインにある質問5件を採用しています。回答や開閉機能は追加していません。
7. 院長挨拶は、原稿と一致するデザインの冒頭1段落と署名を掲載しています。後続3段落の要約・補完は行っていません。
8. 画像19は文章・ボタン込みの書き出しなので、左側の写真部分のみをCSSで切り抜き、右側はHTMLの見出し・本文・リンクとCSS背景で再現しました。二重表示を避け、狭い画面でも同じHTMLを読める構造です。元写真がないため、写真と背景の境界・色は完全一致しません。
9. 画像17はPCでは支給ヒーローを表示し、同じ文言を意味上のHTMLとして保持しています。1180px以下では右側の写真部分を切り抜き、同じHTMLの文言を可視化しています。文字を含めた画像全体の縮小は行っていません。
10. 診療時間横の画像16はHTML/CSSで再構成しました。アクセスの画像21はPCで仮表示し、Gridで重ねた電話・メールの操作領域を用意しています。1180px以下は同じ連絡先を通常のHTMLとして表示します。これらの帯・装飾・アイコンには原画との差があります。
11. 地図画像20は、実在地点を未確定の所在地として表示しないため使用していません。PCでは672×336pxを基準にした空の地図領域だけを確保しました。
12. フォントはJSONにあるBIZ UDPGothic、Noto Sans JP、Zen Maru Gothicを指定し、Yu Gothic・Hiragino・Meiryo等へフォールバックします。確認環境では本文がHiragino Kaku Gothic ProNになりました。フォント差により原画と改行・カード高が異なります。文字を収めるための原稿省略や固定高での切り捨ては行っていません。
13. 正式ロゴ（500×150px・透過PNG）をFigmaのロゴノードと仮画像18（134×40px）、reference.pngのヘッダーと照合し、同じシンボル・和文院名・英文表記・緑系の配色を確認しました。ヘッダーの画像参照を正式素材へ交換しています。元の表示枠は最大134×40pxを維持し、object-fit: containで正式素材の縦横比を保っています。画像のリサイズ加工・再着色は行っていません。ピクセル単位の同一性は未確認です。

## 後から交換する箇所

- ロゴ: `.brand-image` のsrcは正式素材 `assets/images/logo.png` を使用済みです。将来別の正式素材へ交換する場合は、HTMLの元画像寸法とCSSの縦横比も合わせて更新してください。仮画像18は支給素材の控えとして残し、ヘッダーでは参照していません。
- 写真: `assets/images/` 内の各画像と、用途別画像クラス。原画像をそのまま保持しているため、正式画像のパスに交換できます。
- 文字なしのヒーロー・院長画像: `.hero-media`、`.message-photo`。正式素材の比率に応じてCSSの切り抜きを調整します。
- 地図: `[data-map-status="pending"]`。正式仕様を受領後にiframe等へ交換します。
- リンク: `[data-link-status="pending"]`。`data-link-key`で用途を識別できます。
- CMS: `.news-list` の各li。タイトルと詳細URLを同じ構造へ出力してください。

未確定リンクはhrefを持たず、aria-disabled="true"とdata-link-status="pending"を設定しています。仮URL、href="#"、架空の詳細ページは作成していません。正式URLの設定時に未確定状態の属性・クラスを外します。予約は未確定状態です。ページ内ナビゲーションと、支給された電話・メールのみ有効です。

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \

```

```sh
node site/verification/verify.mjs
```
